# Smart Animal Detector System using Arduino Nano and PIR Sensor

## Abstract
This project implements a low-cost smart animal detector for farms and wildlife-sensitive zones. A PIR sensor detects movement, and an Arduino Nano activates LED and buzzer alerts. The system is simple, reliable, beginner-friendly, and suitable for academic submission.

## 1. Introduction
Unwanted animal movement near crops or restricted areas can cause losses. A compact alerting system helps users respond quickly. This project demonstrates an embedded motion-alert design using minimal components.

## 2. Objectives
- Detect movement using PIR sensor
- Trigger immediate LED and buzzer alerts
- Keep implementation simple for students and beginners
- Provide complete report and test workflow for evaluation
