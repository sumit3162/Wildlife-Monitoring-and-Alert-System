## Circuit Connections

### PIR Sensor
| PIR Sensor Pin | Arduino Nano Pin |
|:---:|:---:|
| VCC | 5V |
| GND | GND |
| OUT | D2 |

### Buzzer
| Buzzer Pin | Arduino Nano Pin |
|:---:|:---:|
| +   | D8  |
| -   | GND |

### LED
| LED Pin | Arduino Nano Pin |
|:---:|:---:|
| Positive (+) | D13 |
| Negative (–) | 220Ω Resistor → GND |
