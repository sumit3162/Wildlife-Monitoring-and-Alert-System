# Wildlife Monitoring and Alert System

Arduino Nano based **Smart Animal Detector System** using a PIR motion sensor. When movement is detected, the system activates an LED and buzzer alert for field monitoring.

## Suitable For
- Engineering and Diploma mini/major projects
- IoT and Embedded Systems learning
- Smart agriculture and farm protection
- Wildlife movement monitoring

## Quick Start
1. Open `arduino/SmartAnimalDetector/SmartAnimalDetector.ino` in Arduino IDE.
2. Select board: **Arduino Nano** and the correct COM port.
3. Wire components using `docs/circuit-connections.md`.
4. Upload code and test movement detection using `docs/testing-procedure.md`.

## Project Objective
Detect animal movement in monitored areas and generate immediate local audio-visual alerts.
